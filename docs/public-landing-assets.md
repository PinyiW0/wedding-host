## B. 照片牆本體 ★ 主角

**張數：25~30 張。** 少於 20 張畫布會空、多於 35 張手機會爆。

### B-1. 分區（重要）

純散落的照片沒有敘事錨點，滑完只會覺得「很多照片」。請把照片分成 3 區，
拖曳時區塊會有淡淡的分界：

| 區 | 主題 | 張數 | 你的定義 |
|---|---|---|---|
| 1 | 相識／交往初期 | 8~10 | `<遠距戀愛十一年>` |
| 2 | 一起生活的日常 | 8~10 | `<每天視訊交換日常>` |
| 3 | 求婚與婚禮籌備 | 8~10 | `<不厭其煩的配合>` |

### B-2. 逐張清單

檔名規則：`wall-<區號>-<序號>.jpg`（例：`wall-1-03.jpg`）

| 檔名 | caption | 年份／地點（可選） | 首屏★ |
|---|---|---|---|
| wall-1-01.jpg | `<第一次一起去的海邊>` | `<2019 墾丁>` | ★ |
| wall-1-02.jpg | `<>` | `<>` | |
| ... | | | |

- **caption ≤ 25 字**，用口語，不要寫成圖說（「2019年攝於墾丁」← 不要）
- **「首屏★」請標滿 8~10 張**：這幾張會立刻載入，其餘 lazy load。
  不標的話 30 張一起載，手機開場會白畫面 3 秒。

### B-3. 照片規格

| 項目 | 規格 |
|---|---|
| 比例 | 正方 1:1（我會裁，但主體別壓在正中央邊緣） |
| 長邊 | 800~1200px 就好，**不要給 4000px 原檔** |
| 格式 | JPEG／PNG（HEIC 請先轉檔），我統一轉 WebP |
| 單張 | 轉檔後控制在 150KB 內 |

## C. 便利貼（散在照片之間）

**5~8 張**，純文字，沒有照片。這是照片牆的「章節標」與情緒轉折點。

| 編號 | 文字 | 語氣 |
|---|---|---|
| note-01 | `<那時候還不知道會走到這裡>` | ≤ 30 字，手寫口吻 |
| note-02 | `<>` | |
| ... | | |

> **手寫感字體提醒**：Google Fonts 的繁體手寫選擇很少，模擬出來容易假。
> 兩個選項擇一告訴我：
> (a) 你**真的手寫在便條紙上拍照**給我（最有質感，5~8 張隨手拍即可）
> (b) 接受用襯線體 ＋ 輕微旋轉模擬便利貼，不強求手寫

## H. 交付方式

一個資料夾，裡面：

```
wedding-assets/
├── 文案.md          ← 本檔填好的版本
├── hero-01.jpg
├── wall-1-01.jpg ... wall-3-10.jpg
├── venue-01.jpg ...
└── notes/           ← 若選手寫，便條紙照片放這
```

雲端連結（Google Drive／Dropbox）或直接放進專案都可以。
